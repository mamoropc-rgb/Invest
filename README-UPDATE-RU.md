# Инвестиции — Premium Glass 1.0.1

Обновление интерфейса для репозитория: https://github.com/mamoropc-rgb/Invest

## Какие файлы заменить

Внутри архива сохранена исходная структура папок. Замените в GitHub **ровно 3 существующих файла**:

1. `app/src/main/java/com/mamoro/investments/ui/theme/GlassTheme.kt`
2. `app/src/main/java/com/mamoro/investments/ui/InvestmentsScreen.kt`
3. `app/build.gradle.kts`

**Не создавайте второй `InvestmentsScreen.kt` в другом каталоге!** Он должен быть только в папке `ui`.

В Android-приложении не нужно ничего менять в `data/`, `domain/`, `sync/`, `InvestmentForm.kt`, `MainActivity.kt`, `AndroidManifest.xml`, настройках подписи и workflow.

## Что изменено

- На все страницы добавлена правильная базовая цветовая схема `Surface`, чтобы обычный текст стал светлым на графитовом фоне.
- Усилена читаемость вторичного текста и заголовков, улучшены стеклянные градиенты и обводки.
- Обновлены брендовый значок в шапке, стеклянная нижняя навигация и тень главной кнопки.
- Добавлена заметная кнопка для создания первой бумаги в пустом портфеле и на вкладке «Активы».
- Обновлена версия приложения: `versionCode = 2`, `versionName = "1.0.1"`.

Финансовые формулы, хранение данных, экраны ввода и обмен с «Кошельком» **не изменялись**.

## Загрузка с телефона

1. В GitHub перейдите к каждому из трёх путей выше.
2. Выберите редактирование (карандаш) и полностью замените текст содержимым соответствующего файла из архива.
3. Сохраните в `main` через **Commit changes**, затем откройте **Actions**.
4. Убедитесь, что сборка `:app:testDebugUnitTest :app:lintDebug :app:assembleDebug` завершилась успешно.
5. Установите APK, проверьте пять вкладок, форму добавления бумаги и цвета заголовков.

## Важно о подписи APK

Для установки обновления поверх установленной версии Android требует ту же подпись и тот же `applicationId`. `versionCode = 2` увеличен. Если предыдущая установка была Debug APK с другим ключом, обновление может не устанавливаться. **Не удаляйте установленное приложение до сохранения данных**, если уже вносили инвестиции. Для постоянных обновлений используйте один и тот же Release-ключ из вашего приватного архива; не загружайте ключ в GitHub как обычный файл.

## Проверка

Это исходники для GitHub Actions. Полную Android-сборку локально выполнить в этой среде нельзя, поскольку здесь нет установленного Android SDK и Gradle. Исправления выполнены по актуальным исходникам репозитория и проверены структурно.
