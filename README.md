# Инвестиции — 1.0.7

Android-приложение для акций, облигаций и фондов. Сохранено оформление варианта 3 «Точные данные»: почти чёрный фон, компактные карточки и таблицы, оранжевые действия. [Референс](docs/precise-data-reference.png) · [Правила адаптации](docs/PRECISE_DATA_DESIGN_RU.md).

На телефоне используются пять нижних вкладок. На планшете — боковая навигация и ограниченная по ширине рабочая область. Состояния вкладок и период графика сохраняются.

В 1.0.7 исправлена поддержка сертификата API Т‑Инвестиций. Дополнительный корень из официальных источников действует только для адреса API; устанавливать его в систему не требуется. Проверка связи различает ошибки сертификата, DNS, таймаут, сеть и отказ токена. [Описание исправления](docs/TINVEST_CONNECTION_RU.md).

## Облигации и Т‑Инвестиции

Во вкладке «Ещё» можно сохранить токен «Только чтение». При добавлении облигации доступен поиск по названию, тикеру и ISIN, загрузка сведений о выпуске и купонного расписания. Уже добавленную бумагу можно связать со справочником из её карточки.

Календарь находится в «Аналитике» и в карточке облигации. Прогноз учитывает покупки, продажи, дату фиксации и даты расчётов. Полученные купоны остаются в истории после продажи. Ранее зафиксированное право на купон сохраняется, даже если выплата поступит после продажи. Неизвестные даты и суммы помечаются как оценки или необъявленные значения.

Ожидаемый купон не создаёт доход автоматически. Получение подтверждается фактической суммой после удержаний; ранее введённый доход можно связать с расписанием без дублирования. [Подключение и правила учёта](docs/BONDS_TINVEST_RU.md).

## Остальные возможности

- Покупка и продажа бумаг, комиссии, проверка остатка и средней стоимости.
- Дивиденды, купоны, история с фильтрами, удаление операций с защитой расчётов.
- Ручная текущая цена, структура и результат инвестирования.
- Локальная Room-база, Android 8.0+, офлайн-доступ к сохранённым расписаниям.
- Защищённый протокол событий для связи с основным приложением «Кошелёк».

Учёт ведётся в RUB. Рыночные котировки пока вводятся вручную; график портфеля без реальной истории показывает пустое состояние. Погашение и амортизация отображаются в справочных сведениях и не создают автоматически купонный доход. Покупки и продажи вводятся в приложении, импорт брокерских сделок не выполняется.

Пополнение и вывод остаются операциями Кошелька. Передача событий требует адаптера walletfree и доверенной подписи. До подключения операции хранятся локально. [Контракт синхронизации](docs/SYNC_CONTRACT_RU.md).

## Проверка и обновление

Java 17, Gradle 8.10.2, SDK 35, Kotlin и Jetpack Compose. Расчёты выполняются в копейках и миллионных долях количества.

```sh
gradle :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
gradle :app:assembleRelease
python3 -m unittest discover -s docs -p test_upgrade_policy.py
```

50 Android-тестов проверяют расчёты, API, миграцию, защиту от повторных купонов, интерфейс, область доверия сертификату и обработку сетевых ошибок. Ещё четыре теста проверяют политику сохранности базы при обновлении. SDK Robolectric закреплены по версиям и SHA‑512, в CI используется проверяемый кэш.

GitHub Actions собирает подписанный Release APK и устанавливает 1.0.7 поверх неизменённого подписанного APK 1.0.6. Проверяются все финансовые и купонные таблицы, прежний сертификат подписи и сохранённый через интерфейс тестовый токен. Отдельный workflow снимает установленный Debug APK на телефоне 1080×2400 и планшете 2560×1600, в обеих ориентациях и со шрифтом 150%; проверяет Keystore и область доверия на настоящем Android. Пробный сетевой запрос использует только заведомо недействительный синтетический токен; личная авторизация проверяется пользователем на устройстве.

Room выполняет добавочную миграцию 1 → 2. Прежние финансовые таблицы, Application ID и контракт Кошелька сохраняются. Ключ подписи остаётся в существующих GitHub Actions Secrets. Демонстрационные сцены находятся только в `src/debug`, не записываются в пользовательскую базу и отсутствуют в Release.
