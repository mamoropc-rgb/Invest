# Инвестиции — Premium Glass 1.0.0

**Отдельное Android-приложение для акций, облигаций и фондов**, в согласованном с пользователем визуальном направлении «Вариант 2 — Минимализм и скорость», Premium Glass.

## Уже подготовлено

- Kotlin + Jetpack Compose, Material 3, Android 8.0+;
- тёмный графит, оранжевые акценты, полупрозрачные карточки, анимированное переключение вкладок и итоговой суммы;
- 5 вкладок: Портфель, Активы, Операции, Аналитика, Ещё;
- форма создания бумаги с тикером, типом и ручной текущей ценой;
- покупки и продажи бумаг, комиссии, проверка остатка, расчёт средневзвешенной стоимости и результата сделок;
- дивиденды и купоны, история с фильтрами, удаление операций с защитой расчётов;
- вкладка аналитики: фактическая структура активов и результат инвестирования;
- локальная Room-база, без интернет-разрешения;
- защищённый протокол событий для двусторонней интеграции с главным приложением «Кошелёк»;
- GitHub Actions: тесты, lint, debug и подписанный release при добавленных секретах;
- подготовленный отдельный приватный комплект подписи.

## Ограничения первой версии

**Синхронизация с walletfree ещё не включена**: для неё необходимо изменить сам walletfree (см. `docs/SYNC_CONTRACT_RU.md`), выбрать реальный брокерский счёт, сверить цифровую подпись. Нельзя заявлять о двустороннем обмене, пока оба приложения не протестированы вместе.

Котировки вносятся вручную. Отсутствуют биржевой онлайн-источник и исторические графики цен (нет фиктивных данных). В первой версии поддерживается только RUB; резервное копирование/импорт — в плане следующего этапа. Временной период текущих расчётов — все записи с даты создания (дневных снапшотов пока нет).

**Не копировались исходники walletfree**, поскольку указанный репозиторий не удалось получить; стиль создан на основе согласованного изображения Premium Glass. В `docs/premium-glass-reference.png` находится визуальный ориентир.

## Архитектура

- `app/src/main/java/.../data` — Room и репозиторий;
- `domain` — точные расчёты в копейках / миллионных долях;
- `sync` — защищённый ContentProvider + журнал событий;
- `ui` — Compose-экраны, формы, Premium Glass;
- `walletfree-integration` — пример кода стороны Wallet; не входит в сборку приложения;
- `.github/workflows/android.yml` — тесты и выпуск APK.

## Сборка

Java 17 / Gradle 8.10.2 / Android SDK 35. На GitHub Gradle устанавливается action `gradle/actions/setup-gradle@v4`, поэтому `gradlew` в архиве не требуется.

Локально при установленном Gradle 8.10.2:

```bash
gradle :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Инструкция с телефона: [`docs/INSTALL_FROM_ANDROID_RU.md`](docs/INSTALL_FROM_ANDROID_RU.md).

## Подпись

Ключ находится **отдельно** от исходников. Для сборки релиза требуются четыре GitHub Actions Secret. Инструкция в документе установки. Никогда не добавляйте приватный ключ в git, issues, PR или чат с третьими лицами.
