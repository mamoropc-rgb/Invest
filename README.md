# Инвестиции — 1.0.5 «Точные данные»

Отдельное Android-приложение для акций, облигаций и фондов. Интерфейс воспроизводит выбранный вариант 3: почти чёрный фон, компактные карточки и таблицы, оранжевые действия. Эталон — [docs/precise-data-reference.png](docs/precise-data-reference.png), правила адаптации — [docs/PRECISE_DATA_DESIGN_RU.md](docs/PRECISE_DATA_DESIGN_RU.md).

На телефоне используются пять нижних вкладок. На планшете — боковая навигация, график и таблица активов слева, структура и последние операции справа, категории внизу. При узкой области и увеличенном шрифте блоки перестраиваются в прокручиваемую колонку. Состояния вкладок и период графика сохраняются при переключениях.

## Возможности

- Покупка и продажа бумаг, комиссии, проверка остатка, средневзвешенная стоимость и результат сделок.
- Дивиденды и купоны, история с фильтрами, удаление операций с защитой расчётов.
- Создание бумаги, тикер, тип и ручная текущая цена.
- Аналитика фактической структуры и результата инвестирования.
- Локальная Room-база, Android 8.0+, без интернет-разрешения.
- Защищённый протокол событий для связи с главным приложением «Кошелёк».

## Реальные данные и ограничения

Суммы в обычном приложении берутся только из пользовательских операций. Демонстрационная сцена для сравнения с референсом находится исключительно в `src/debug`, живёт в памяти и отсутствует в Release.

История рыночных оценок пока не собирается. Вместо вымышленной линии график показывает пустое состояние; результат открытых позиций не выдаётся за дневную доходность. Котировки вводятся вручную, онлайн-источник пока не подключён. Поддерживается RUB; резервное копирование и импорт пока не реализованы.

Дивиденды и купоны показываются как полученный доход, отдельно от долей открытых активов. Двусторонняя синхронизация заработает после установки адаптера в walletfree, выбора брокерского счёта и настройки доверенной подписи. До этого операции хранятся локально и не меняют баланс Кошелька. Пополнение и вывод остаются операциями Кошелька. См. [контракт синхронизации](docs/SYNC_CONTRACT_RU.md).

## Проверка и сборка

Java 17, Gradle 8.10.2, Android SDK 35. Kotlin и Jetpack Compose; финансовые расчёты в копейках и миллионных долях количества.

```sh
gradle :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
gradle :app:assembleRelease
```

GitHub Actions запускает 13 тестов, lint, Debug и подписанную Release-сборку. Отдельный сценарий устанавливает 1.0.5 поверх неизменённого подписанного APK 1.0.4 и сравнивает данные. Сценарий визуальной проверки снимает установленный Debug APK на телефоне 1080×2400 и планшете 2560×1600, обе ориентации планшета и шрифт 150%.

Финансовые расчёты, Room, Application ID и контракт walletfree в этом обновлении сохранены. Ключ подписи остаётся вне репозитория; используются существующие четыре GitHub Actions Secret. [Установка с телефона](docs/INSTALL_FROM_ANDROID_RU.md).
