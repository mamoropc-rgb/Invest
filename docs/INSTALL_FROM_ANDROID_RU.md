# Установка обновления с телефона

1. Откройте [релизы Invest](https://github.com/mamoropc-rgb/Invest/releases) и выберите версию 1.0.7.
2. В разделе Assets скачайте `Investments-1.0.7-release-signed.apk`.
3. Откройте APK и выберите **Обновить**. Удалять предыдущую версию не требуется.
4. После установки откройте **Ещё → Т‑Инвестиции** для настройки справочника облигаций. [Пошаговая инструкция](BONDS_TINVEST_RU.md).

Поддерживается Android 8.0+. Application ID прежний: `com.mamoro.investments`. Release собирается существующим ключом. Проверка обновления в GitHub Actions сравнивает подпись, структуру прежних таблиц и сохранённые записи.

Альтернативный способ получения APK: откройте успешный запуск **Actions → Android - test, build, signed release**. Артефакт `Investments-1.0.7-release-signed` содержит подписанный APK. Артефакты проверок содержат результаты тестов, отчёт о сохранности базы и снимок после установки обновления.

В 1.0.7 исправлена поддержка сертификата Т‑Инвестиций и добавлены точные сообщения об ошибках связи. Сохранённый токен остаётся на устройстве. После обновления откройте **Ещё → Т‑Инвестиции → Проверить связь**.

Исходники доступны в репозитории и в архиве релиза. Личный токен Т‑Инвестиций вводится в приложении, в репозиторий он не загружается. Действующие секреты подписи не меняются.
