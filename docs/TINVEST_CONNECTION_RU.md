# Подключение Т‑Инвестиций: сертификат и диагностика

Версия 1.0.6 сводила ошибки HTTPS, DNS, таймауты и другие сетевые ошибки к одной
надписи «Нет связи … Проверьте интернет». Сохранённый токен не подтверждал успешную
авторизацию. По такой надписи нельзя было определить причину отказа на устройстве.

API Т‑Банка требует доверия к Russian Trusted Root CA. Этот корень обычно отсутствует
в стандартном хранилище Android. В приложение добавлен публичный сертификат, доступный
из двух официальных источников; их файлы побайтно совпали 22.11.2026:

- [Страница Т‑Банка](https://status.tbank-online.com/certificates/)
- [Файл Т‑Банка](https://help-static2.tbank-online.com/certs/Android/Root/Russian_Trusted_Root_CA.cer)
- [Файл Госуслуг](https://gu-st.ru/content/Other/doc/russian_trusted_root_ca.cer)
- [Требования Invest API](https://developer.tbank.ru/invest/intro/developer/network)

В ресурсе приложения окончания строк нормализованы в LF. SHA‑256 этого файла:

Срок действия: 01.03.2022–27.02.2032. Закрытого ключа в файле нет.

## Область доверия

Дополнительный корень применяется стандартным Android Network Security Configuration
только к `invest-public-api.tbank.ru`, без поддоменов. Системные корни сохранены;
пользовательские хранилища и произвольные сертификаты не включены.
Проверки цепочки, срока действия и HTTPS-имени сервера продолжают выполняться Android.
HTTP запрещён, автоматические перенаправления с токеном запрещены.
Устанавливать сертификат в системные настройки устройства не требуется.

## Различимые ошибки

Проверка связи и поиск теперь отдельно сообщают о проблеме сертификата, таймауте,
ошибке DNS, сетевом отказе, недействительном токене, недостаточных правах и ответе
сервера. Для HTTP-ошибок указан статус. Исходные тексты исключений, тела ошибок,
заголовки и токен не выводятся в интерфейс или логи.

Скриншот пользователя подтверждает сетевой отказ старой версии, но не доказывает
именно ошибку сертификата. Личная авторизация проверяется только на устройстве:
**Ещё → Т‑Инвестиции → Проверить связь**. При сохранении ошибки новая версия
покажет её категорию без раскрытия токена.
