# Установка 1.0.3 через GitHub с телефона

Репозиторий: https://github.com/mamoropc-rgb/Invest

## Вариант PATCH (предпочтителен)

Распакуйте ZIP PATCH. В нём пять файлов с сохранёнными путями и инструкция.
В GitHub откройте существующие файлы по тем же путям и замените содержимое (или загрузите файлы в их точные папки):

- app/src/main/java/com/mamoro/investments/ui/theme/GlassTheme.kt
- app/src/main/java/com/mamoro/investments/ui/InvestmentsScreen.kt
- app/src/main/java/com/mamoro/investments/ui/InvestmentForm.kt
- app/build.gradle.kts
- .github/workflows/android.yml

Важно: **НЕ** создавайте вторую копию InvestmentsScreen.kt в папке `.../investments/` без `ui/`.
После изменения нескольких файлов выполните один коммит `UI 1.0.3: premium glass polish`.
Файл private keystore никогда не загружайте в GitHub. Workflow использует прежние секреты `INVESTMENTS_*`.

## Проверка и получение APK

1. Actions -> выберите новый зелёный запуск -> Artifacts.
2. Должны появиться `Investments-1.0.3-debug` и (при наличии secrets) `Investments-1.0.3-release-signed`.
3. Для обновления установленной подписанной версии **используйте только `app-release.apk` из `Investments-1.0.3-release-signed`**.
4. Сверьте версию в приложении: «Инвестиции 1.0.3 · Android 8.0+».
5. Если Android сообщает о конфликте пакета: не удаляйте приложение с данными! Это может означать конфликт подписей. Сначала обеспечьте резервное копирование.

## Чек-лист внешнего вида

- Телефон 1080×2400: проверка 5 вкладок, 5 карточек на Главной, кнопки быстрого действия и нижнего меню при системном увеличении текста.
- Планшет 2560×1600: контент должен быть отцентрирован, карточки не растянуты во всю ширину, навигация не шире 630 dp.
- В меню «Быстрые действия» проверить наличие кнопки закрытия, формы «Купить»/«Продать»/«Дивиденд»/«Купон»/«Добавить бумагу».
- На пустом портфеле круговые диаграммы должны быть нейтральными, без выдуманных трендов и процентов.
- Прокрутка, перелистывание и сохранение операции не должны зависать; цвета текста остаются читаемыми.
