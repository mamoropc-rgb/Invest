# Обновление «Инвестиции» 1.0.2 через GitHub на телефоне

Репозиторий: https://github.com/mamoropc-rgb/Invest

## Самый короткий путь (патч)

Скачайте `Investments-PremiumGlass-1.0.2-PATCH.zip`, распакуйте его на телефоне и **замените** соответствующие файлы в существующем репозитории **без изменения папок**:

1. `app/build.gradle.kts`
2. `app/src/main/java/com/mamoro/investments/ui/theme/GlassTheme.kt`
3. `app/src/main/java/com/mamoro/investments/ui/InvestmentsScreen.kt`
4. `app/src/main/java/com/mamoro/investments/ui/InvestmentForm.kt`
5. `.github/workflows/android.yml`
6. `docs/UI_1_0_2_RELEASE_NOTES_RU.md` (новый файл, необязателен для компиляции)

В GitHub на телефоне проще открывать каждый файл и выбирать **Edit**, либо загружать файл в нужную папку с заменой, если интерфейс GitHub это позволяет. `ZIP` нельзя просто загрузить в корень и ожидать, что GitHub распакует его автоматически.

Сохраните изменения одним коммитом, например `UI: Premium Glass 1.0.2 phone and tablet`. Это обновление одной цельной дизайн-системы, поэтому файлы темы и экрана должны быть обновлены вместе.

После загрузки откройте **Actions → Android - test, build, signed release**. Найдите **новый** запуск. Названия новых архивов будут `Investments-1.0.2-debug` и (при наличии Secrets) `Investments-1.0.2-release-signed`.

## Подпись и сохранность данных
Не загружайте приватный JKS и его пароли. Для обновления поверх предыдущей установленной Debug-версии берите Debug APK с той же debug-подписью; для установленной Release-версии используйте Release APK, подписанный тем же JKS.

Если система сообщает «Не установлено» из-за несовпадения подписи, **не удаляйте установленное приложение**, пока не создана безопасная резервная копия данных.

## Проверка
Откройте «Ещё», внизу должно быть `Инвестиции 1.0.2 · Android 8.0+`. Проверьте пять вкладок, добавление бумаги, сделки, выплаты и сохранение данных. На планшете — центральную колонку и ограниченную ширину панели.

**Статус проверки:** Kotlin-файлы прошли локальную синтаксическую проверку парсером. Компиляция Android и визуальная проверка на реальных устройствах остаются обязательными после загрузки исходников в GitHub Actions.
