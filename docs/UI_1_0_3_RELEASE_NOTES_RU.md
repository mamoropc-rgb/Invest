# Инвестиции — Premium Glass 1.0.3 (визуальная полировка)

Исходная база: репозиторий mamoropc-rgb/Invest, ветка main, версия 1.0.2.
Эталон: вариант 2 «Минимализм и скорость» с оформлением Premium Glass.

## Изменения интерфейса

1. GlassCard: светлые отражения, дополнительное радиальное свечение, обновлённые градиенты и двухтональная рамка; компактные карточки для списков и быстрых действий.
2. Главный экран: акцент на сумме портфеля; мягкая подсветка за суммой (это НЕ вымышленный график цены); плавная смена чисел.
3. Оранжевые кнопки: общий градиентный компонент GlassActionButton с одинаковой высотой, контрастными подписями и световой границей.
4. Нижняя навигация: более выраженное стекло, анимированная подсветка выбранной вкладки, отдельный максимум ширины 630 dp для планшета.
5. Быстрые действия: полупрозрачная панель, понятный заголовок, кнопка закрытия, согласованные компактные строки.
6. Фильтры: 48 dp высота зоны касания, единые градиенты и контраст активного состояния.
7. Аналитика: в центре круговых диаграмм теперь отображается сумма, рассчитанная из существующих данных (без придуманных цен).
8. Формы: слегка усилен стеклянный фон полей, операции и валидация прежние.
9. Сохранена адаптация 6,55-дюймового телефона (1080×2400) и 12,1-дюймового планшета (2560×1600): размеры в dp, ограничение ширины главной колонки до 704 dp.
10. Версия: 1.0.3, versionCode 4.

## Что принципиально не менялось

- Room, DAO, модель инвестиций, операции купли-продажи, купоны, дивиденды, MoneyMath, PortfolioMath, ViewModel, ContentProvider.
- Связь с walletfree всё ещё требует установки адаптера в Кошельке, синхронизация не включена.
- Нет искусственных графиков цен: исторические котировки не подключены.
- Локальная подпись НЕ вложена в архив, использован существующий GitHub workflow с секретами.

## Ограничения проверки

- Статические проверки структуры Kotlin/скобок пройдены.
- Выверено побайтовое совпадение ключевых файлов данных и бизнес-логики с версией 1.0.2.
- Компиляция Android, UI-тесты на физических устройствах и попиксельное сравнение с макетом здесь не выполнены. Их нужно проверить в GitHub Actions и на устройствах.
