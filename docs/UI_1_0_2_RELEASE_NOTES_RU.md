# Инвестиции 1.0.2 — Premium Glass, вариант 2

Доработка интерфейса по эталону «Вариант 2 — Минимализм и скорость» (в репозитории: `docs/premium-glass-reference.png`).

## Поддерживаемые экраны
- Телефон: 6,55″ AMOLED, 1080 × 2400 пикселей (портретная ориентация).
- Планшет: 12,1″ IPS, 2560 × 1600 пикселей (проверить портретный и горизонтальный режим).

Размеры в Compose задаются в независимых от плотности пикселях `dp`, **не в пикселях дисплея**. При ширине окна от 600 dp интерфейс центрируется и ограничивается до 704 dp. На телефоне используется колонка во всю доступную ширину с боковыми полями 16 dp; на планшете — поля 24 dp внутри центральной колонки. Навигация тоже ограничена этой шириной.

## Что меняется
1. Общее оформление: мягкий графитовый фон, тёплый акцент, стеклянные карточки с верхним бликом и градиентной обводкой.
2. Единая система размеров: радиус карточек, отступы, основные и вторичные тексты и нижняя навигация.
3. Главный экран: компактная сводка, пять одинаково выровненных строк, яркая кнопка быстрых действий и понятное пустое состояние.
4. Активы: стеклянные фильтры, одинаковые строки позиций, выбор бумаги и пустое состояние.
5. Операции: фильтры «Все / Покупки / Продажи / Выплаты», группировка по дате, компактные суммы и время.
6. Аналитика: структура портфеля, финансовые результаты и **реальные** выплаты без вымышленной динамики рынка.
7. Настройки: стиль пяти вкладок, адаптация списка брокерских счетов, действительный статус синхронизации.
8. Формы: обновлены поверхности и обводки полей ввода. Механика сохранения не менялась.

## Что не меняется
- Room, таблицы, схема данных, DAO и репозиторий;
- операции покупок, продаж, купонов и дивидендов;
- существующий протокол обмена с кошельком (адаптер по-прежнему требуется);
- логика расчётов, суммы и формулы.

## Важно
Стеклянный вид здесь реализован полупрозрачными многослойными градиентами, бликами, обводками и тенями **без настоящего blur заднего содержимого**, чтобы сохранить плавность на Android 8.0+. Это максимально близкая практическая стилизация, а не гарантия попиксельного совпадения со сгенерированным изображением.

## Контроль после публикации исходников
1. Убедиться в версии 1.0.2 в `app/build.gradle.kts` и на вкладке «Ещё».
2. Проверить, что GitHub Actions отработал `testDebugUnitTest`, `lintDebug`, `assembleDebug`.
3. Скачать `Investments-1.0.2-debug` либо `Investments-1.0.2-release-signed` в соответствии с уже установленной подписью.
4. На телефоне пройти все вкладки, раскрыть быстрые действия, форму добавления, клавиатуру и фильтры.
5. На планшете проверить портрет/альбом, масштаб шрифтов 100%/130%, отсутствие растяжения/обрезания, положение панели внизу.
6. Добавить тестовую бумагу, покупку, купон; проверить историю, сумму, выход из приложения и повторный вход. После проверки тестовые данные удалить.

Приватную подпись приложения и её пароли **не загружать в репозиторий**. Для подписанного Release APK необходимы прежние GitHub Secrets; не менять ключ между обновлениями.
